# 컨텍스트 노트

## 결정 사항
- **새 컬럼 대신 기존 `suspended` status 재사용.** 큐 함수와 진행률 집계가 이미 이 값을 알고 있어서 변경 범위가 가장 작다.
- **복원 시 상태 결정은 DB 함수에서.** 웹/모바일 두 클라이언트에 같은 로직을 중복하지 않기 위해 RPC로 묶는다.
  - `interval >= 1` → `review` (기존 due_date 유지)
  - 그 외 `last_reviewed_at`이 있으면 → `learning`, step 0, due now
  - 아니면 → `new`, due now
- **복원 시 `lapse_count`를 0으로 리셋.** 리치로 자동 정지된 카드를 다시 넣었을 때 다음 again 한 번에 또 정지되는 걸 막기 위함.
- **UI 위치는 카드 편집 페이지의 토글.** 목록에서 카드를 탭하면 편집 페이지로 가므로 가장 자연스러운 자리. 선택 모드 일괄 제외는 이번 범위에서 제외.
- **통계 박스(모름/배우는중/복습예정/암기완료)는 건드리지 않음.** 서버 집계가 이미 suspended를 따로 세고 있어서 네 박스 합계와 total이 안 맞을 수 있으나, 기존 리치 동작과 동일하므로 그대로 둔다.
